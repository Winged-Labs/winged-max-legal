# Winged Max public policies

Public policy pages for Winged Max, the macOS service offered by Winged Oy. The separate Winged member-matching app has different terms and billing.

- [Overview](https://winged-labs.github.io/winged-max-legal/)
- [Terms and Conditions](https://winged-labs.github.io/winged-max-legal/terms/)
- [Acceptable Use Policy](https://winged-labs.github.io/winged-max-legal/acceptable-use/)
- [Law-Enforcement Request Protocol](https://winged-labs.github.io/winged-max-legal/law-enforcement/)

These pages describe a prelaunch US pilot; they do not enable live Stripe payments. A Max-specific privacy notice, legal-counsel review, tax review, and Stripe's explicit approval remain launch prerequisites.
